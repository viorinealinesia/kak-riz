# Untuk Kakak — Semangat Selalu, ya! ♡

Website ucapan penyemangat dengan gaya dreamy, cute, pink pastel, cream, amplop hati, jendela malam, bunga, dan kucing.

## File
- `index.html` — konten website
- `style.css` — seluruh desain responsif dan animasi
- `script.js` — tombol surat, kejutan, navigasi mobile, musik
- `assets/favicon.svg` — favicon hati

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Tombol “Dengarkan Bernaung” membuka pemutar YouTube untuk lagu resmi “Bernaung” oleh Feby Putri. Koneksi internet diperlukan. Pemutaran dimulai saat pengunjung menekan tombol play pada pemutar YouTube; browser biasanya memblokir autoplay bersuara.

Musik tidak disertakan di paket ini. Kamu bisa mengganti teks surat dan judul langsung di `index.html`.
